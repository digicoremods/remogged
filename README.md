# reMOGGed

reMOGGed is an add-on for reTHAWed (10K Rising's mod for *Tony Hawk's American Wasteland*, PC):
16-player online lobbies, a smooth 120 FPS, voice chat and more, shared with everyone who runs it.
This is a **beta**.

## Download

Get **reMOGGed-Setup.exe** from [Releases](https://github.com/digicoremods/remogged/releases/latest),
run it and pick your reTHAWed Game folder. You need THAW and reTHAWed installed first.

Official downloads: [GitHub Releases](https://github.com/digicoremods/remogged/releases) and
[digicoremods.com](https://digicoremods.com).
